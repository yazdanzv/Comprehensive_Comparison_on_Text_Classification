# Comprehensive_Comparison_on_Text_Classification

## Code guide

`main.ipynb` is the experiment workflow for text classification and model evaluation. `preprocess.py` cleans and tokenizes text, `vectorizer.py` builds text features, and `embedding.py` provides embedding-based representations. The modules use NLTK, scikit-learn, Gensim, and NumPy. Run the notebook from the repository root after installing its imports and any NLTK resources requested by the preprocessing code. `Report_no5.pdf` is the accompanying report.
